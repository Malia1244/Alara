AUTH SETUP (once)
-----------------
1. In Supabase → SQL Editor, run these files in order:
   supabase/migrations/001_user_isolation.sql
   supabase/migrations/002_fix_user_stats.sql
   supabase/migrations/003_fix_shop_purchases_pkey.sql
   supabase/migrations/004_ara_memories.sql
   supabase/migrations/005_enable_rls.sql
   supabase/migrations/006_community_messages.sql
   supabase/migrations/007_lounge_images.sql
   supabase/migrations/008_calendar_events.sql
   supabase/migrations/009_avatars.sql
   supabase/migrations/010_storage_write_lockdown.sql
   supabase/migrations/011_gift_card_redemptions.sql
   (005 turns on Row Level Security — required to fix “table publicly accessible”)
   (006 creates the shared Lounge chat every signed-in student can use)
   (007 lets Lounge posts include photos and replies for assignment help)
   (008 adds personal calendar events)
   (009 adds changeable profile pics for Lounge)
   (010 blocks browser uploads to photo buckets — API only)
   (011 gift card claims in Shop — check gift_card_redemptions for pending)
2. In Supabase → Authentication, enable Email provider.
   (Optional) turn OFF "Confirm email" while testing locally.
   For "Forgot password": Authentication → URL Configuration
   - Site URL = your app (http://localhost:3000 locally, or Vercel URL)
   - Redirect URLs must include http://localhost:3000/reset-password
     and https://YOUR-VERCEL-URL/reset-password
3. Add to frontend/.env.local:
   NEXT_PUBLIC_SUPABASE_URL=...
   NEXT_PUBLIC_SUPABASE_ANON_KEY=...
   (from Supabase → Project Settings → API)

To start backend:
open a new terminal
cd backend
.\.venv\Scripts\Activate.ps1
python main.py

To start frontend:
open a new terminal
cd frontend
npm run dev

Then open http://localhost:3000 and create an account / sign in.

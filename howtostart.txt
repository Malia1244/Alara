AUTH SETUP (once)
-----------------
1. In Supabase → SQL Editor, run these files in order:
   supabase/migrations/001_user_isolation.sql
   supabase/migrations/002_fix_user_stats.sql
   supabase/migrations/003_fix_shop_purchases_pkey.sql
   supabase/migrations/004_ara_memories.sql
   supabase/migrations/005_enable_rls.sql
   (005 turns on Row Level Security — required to fix “table publicly accessible”)
2. In Supabase → Authentication, enable Email provider.
   (Optional) turn OFF "Confirm email" while testing locally.
3. Add to frontend/.env.local:
   NEXT_PUBLIC_SUPABASE_URL=...
   NEXT_PUBLIC_SUPABASE_ANON_KEY=...
   (from Supabase → Project Settings → API)

To start backend:
open a new terminal
cd backend
.\.venv\Scripts\Activate.ps1
python main.py

To start frontend:
open a new terminal
cd frontend
npm run dev

Then open http://localhost:3000 and create an account / sign in.
